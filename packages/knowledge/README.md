# packages/knowledge — generated knowledge

Every file here is written by a build script and starts with `// Generated by`.
Do not edit them by hand; edit the source and regenerate.

| File | Source | Script |
|---|---|---|
| `com/hopa/knowledge/AppCatalog.kt` | `services/brain/knowledge/apps/*/APP.md`, `.../sites/*/SITE.md` | `tools/scripts/build-app-catalog.py --kotlin packages/knowledge/src/main/kotlin/com/hopa/knowledge/AppCatalog.kt` |
| `com/hopa/knowledge/ApprovalPolicyData.kt` | `spec/policy/approval.v1.json` | `tools/scripts/build-policy-data.py --kotlin packages/knowledge/src/main/kotlin/com/hopa/knowledge/ApprovalPolicyData.kt` |
| `com/hopa/knowledge/PromptRules.kt` | `spec/prompts/rules.v1.json` | `tools/scripts/build-prompt-rules.py --kotlin packages/knowledge/src/main/kotlin/com/hopa/knowledge/PromptRules.kt` |

The same scripts also write the ArkTS copies under `apps/harmony`, and `--check`
fails when either side is stale.

Why a separate module: `packages/engine` does not carry 1,600 lines of generated
data, and knowledge is replaceable without touching the loop. Nothing here may
depend on another module.
